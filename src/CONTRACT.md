```

├── index.html               # 생성물 (직접 편집 금지)
├── shot.sh                  # 움직이는 그림 캡처 (headless Chrome)
├── images/                  # build.py 가 _slides/ 에서 문서가 참조한 것만 복사
├── _slides/                 # 슬라이드 PNG 원본 (읽기 전용, git 제외)
├── _text/                   # 슬라이드 텍스트 (읽기 전용)
├── _pdf/                    # PPTX→PDF 변환본 (읽기 전용)
└── src/

    ├── anims/*.js           # 움직이는 그림 각 1파일, ANIMS["이름"] = {...} (§7)
    ├── test_sims.js / test_anims.js / test_render.js   # node 자동 검사
```

## 2. 문서 파일 형식 (`src/articles/{정렬번호}_{key}.wiki`)
```
key: 하향 처리
title: 하향 처리 (Top-down Processing)
category: 4장 감각과 지각, 용어
---
(본문. 아래 문법)
```
- `key` = 다른 문서가 `[[key]]` 로 참조하는 문자열. **반드시 §5 의 정식 키 목록을 쓸 것** (새 키가 필요하면 §5 표 형식대로 추가하고 파일도 만들 것 — 단 교재 용어를 멋대로 추가하지 말 것. 슬라이드·정리본·bank 에 실제로 나온 것만).
- `title` = 한국어 표기 + 영어 원어 병기(슬라이드에 영어가 있으면 그 철자 그대로). 인물은 `빌헬름 분트 (Wilhelm Wundt, 1832–1920)` 식(생몰년은 확실할 때만).
- `category` 는 쉼표 구분. **첫 항목 = 사이드바 그룹 이름(아래 7+2개 중 하나, 철자 그대로)**, 둘째 항목 = 문서 성격(`메인` / `용어` / `학자` / `이론` / `실험` / `연구 방법` / `뇌 구조` / `안내` / `시험`).
  - 그룹 이름: `안내` · `서막 심리학 이야기` · `1장 심리과학을 비판적으로 생각하기` · `2장 마음의 생물학과 의식` · `3장 일생에 걸친 발달` · `4장 감각과 지각` · `5장 학습` · `6장 기억` · `시험 대비`
- 파일명 정렬번호: **00 안내, 10 서막, 20 1장, 30 2장, 40 3장, 50 4장, 60 5장, 70 6장, E0 시험 대비**. 장 메인 문서가 `{d}0`, 사전 문서가 `{d}1`~`{d}9`, `{d}A`~`{d}Z` (36진 접미, 장당 최대 36개). 파일명은 §5 표에 적힌 그대로 쓴다. 키에 `/` 가 들어가면 파일명에서만 `_` 로 바꾼다(현재 목록에는 없음).

|---|---|
| `== 제목 ==`, `=== 소제목 ===`, `==== 소소제목 ====` | h2/h3/h4 (자동 목차) |
| `'''굵게'''`, `''기울임''`, `` `code` `` | 인라인 |
| `* 항목` / `# 번호항목` | ul / ol (한 줄 = 한 항목, 중첩 없음) |
| `[[키]]`, `[[키|표시문구]]` | 위키 링크 (없는 키는 회색 stub 표시 → 반드시 있는 키만) |
| `[[img:L4-19.png|캡션|small/medium/large]]` | 슬라이드 캡처 (한 줄에 단독으로) |

| `{info}…{/info}` `{warn}…{/warn}` `{tip}…{/tip}` `{joke}…{/joke}` | 참고/주의/팁/여담 박스 |

| `{def}…{/def}` | 📖 정의 박스 — **설명 → 명칭** 방향 (§4-11) |
| `{quiz}…{/quiz}` | ❓ 예상문제 박스 |
| `{answer}…{/answer}` | 접힌 정답 (클릭해서 펼침) — quiz 바로 뒤에 |
| `{exam}…{/exam}` | 🎯 출제 포인트 박스 (교수가 녹음에서 강조한 것·시험 공지·통합요약 출제 예상) |
| 박스는 여러 줄 가능 (`{info}` 로 시작해 `{/info}` 로 끝나는 줄까지) | |

| ↑ 중 `txt` / `ascii` 블록 안에서만 | `'''굵게'''` 와 `[[키]]` / `[[키\|표시]]` 가 추가로 처리된다. `c` / `asm` / `sh` / 클래스 없는 `<pre>` 는 완전히 raw |
| `{|` / `! 헤더 || 헤더` / `|-` / `| 셀 || 셀` / `|}` | 표 (비교표·인물 카드·실험 카드) |
| `$…$` | KaTeX 인라인 수식 (베버의 법칙 $\Delta I / I = k$ 정도로 드물게) |
| `----` | 수평선 |

주의: 코드 블록 안에서는 문법 처리 안 함. 표 셀 안에서는 인라인 문법만.

## 4. 문서 작성 규칙
1. **한국어 산문 + 슬라이드의 영어 원어는 그대로 병기** ("[[하향 처리]](top-down)", "[[신호 탐지 이론]](Signal Detection Theory)"). 교수·슬라이드가 쓰는 한국어 번역어(예: `지각 갖춤새`, `계기적 근사법`, `이중 은폐`, `말표현 효과`)를 **임의로 다른 번역어로 바꾸지 말 것** — 단답형 채점이 그 명칭으로 된다. 교재·타 번역어(예: 이중맹목, 지각 세트, 반두라의 보보 인형)는 "다른 이름" 으로 병기만.
2. 나무위키 톤: 개요 → 본문(슬라이드 순서) → 관련 문서. 잡담/여담(`{joke}`) 허용, 그러나 사실은 **슬라이드·정리본 기준**으로 정확히. 슬라이드·정리본·bank 에 없는 교재 내용(예: 에인스워스의 낯선 상황 실험, 매슬로의 욕구 위계 단계별 설명, 통계 공식)은 쓰지 않는다.
3. **코드 블록 대신 비교표·인물 카드·실험 카드·ASCII 절차 도식.**
   - **인물 카드**(학자 문서 + 학자가 핵심인 이론/실험 문서 상단): 2열 표 `이름(원어) / 학파·분야 / 핵심 주장·업적 / 관련 실험·연도(슬라이드 표기) / 시험 포인트`.
   - **실험 카드**(실험 문서): `연구자(연도) / 질문 / 절차 / 결과 / 결론 / 함정` 표 + 바로 아래 `<pre class="ascii">` 절차 도식(예: `[NS:종] → [US:먹이] → UR(침)  ×반복  →  [CS:종] → CR(침)`).
   - **비교표**: 헷갈리는 짝(구조주의 vs 기능주의, 정적 강화 vs 부적 강화 vs 처벌, 원추체 vs 간상체, 순행 vs 역행 간섭 …)은 반드시 표로. 정리본 "헷갈리는 개념 대비" 를 그대로 활용.
   - 절차가 단계적으로 값이 바뀌면 `[[sim:]]`, 흐름이 핵심이면 `[[anim:]]` 을 바로 아래에 둔다.
4. **모든 학자·이론·실험·용어는 문서에서 첫 등장 시 [[링크]]**: 예 `[[빌헬름 분트]]`, `[[무조건 자극|US]]`, `[[부적 강화]]`, `[[앳킨슨-시프린 모형|다중 저장고 모형]]`. §5-9 의 "흡수 명칭" 은 `[[호스트 키|흡수 명칭]]` 으로 링크한다(예: `[[활동 전위|탈분극화]]`, `[[집단화|폐쇄]]`).
5. 문서마다 최소 `{analogy}` 1개, 시각자료(`[[img:]]` / `[[sim:]]` / `[[anim:]]` / 표 / ascii 그림) 1개 이상. **장 메인 문서는 실제 슬라이드 캡처 5장 이상 + 움직이는 그림 1개 이상**. 사전 문서도 근거 슬라이드에 그림·표·그래프가 있으면 캡처 1장을 넣는다.
6. 캡처 고르는 기준: 그림/표/그래프/실험 패러다임 도식이 있는 슬라이드(오른쪽 그림 캡션이 있는 페이지 대부분). 글자만 있는 슬라이드는 캡처 대신 본문으로.
7. 각 장 메인 문서 끝에 `== 시험 대비 핵심 요약 ==` 번호 목록, `== 관련 문서 ==` 링크 목록. 메인 문서는 슬라이드 순서대로 `== p.N–M 제목 ==` 절을 두고, 각 절에서 그 절의 사전 문서로 링크한다.
8. 사전 문서는 짧아도 됨 (def 박스 + 슬라이드 근거 p.N + 예시/비유 + 헷갈리는 짝 + 관련 링크 2~3개). 그러나 stub 이 아니라 실제 내용. 끝에 `근거: N장 p.X` 한 줄.
9. **정리본 재활용**: `../정리본/{N}주차_{장}_정리.md` 의 "🎙 실제 수업 기록"·⭐ 표시·명칭 암기표·교수 예시(예: 베버 100kg→110→121, 얼굴 13개, 약물 금단=부적 강화, 「제이슨 본」=역행성/「메멘토」=순행성)를 본문에 녹이고, **교수가 강조한 문장·통합요약 §0-1 "교수 강조" 는 `{exam}` 박스**로. 녹음 근거는 `(🎙 9/22)` 처럼 날짜를 붙인다.
10. **모의고사 bank 재활용**: 각 문서의 근거 페이지와 같은 출처(`N장 p.X`)를 가진 bank 문항의 **오답 보기·해설의 함정**을 `{warn}` 또는 `{quiz}`+`{answer}` 로 옮긴다(문장 그대로 복붙 말고 재구성). **알려진 슬라이드 오류는 `{warn}` 으로 명시하고 정답으로 가르치지 말 것**:
    - 4장 p.25 "우시야의 입력 정보는 **우반구**로" → 올바른 내용은 **좌반구** (2장 p.29 와 일치).
    - 6장 p.18 PPTX 표기 "**72개**" → **7±2개** (조지 밀러의 매직 넘버 7).
    - 5장 p.4·p.17 "**Operational** Conditioning" → 올바른 원어는 **Operant** Conditioning(조작적 조건화).
11. **단답형은 명칭 쓰기만** 나오므로 `{def}` 박스는 **"설명 → 명칭"** 방향으로 쓴다. 형식:
    ```
    {def}
    '''설명''': 결과를 알고 난 뒤, 자신이 그 결과를 예측할 수 있었다고 믿는 경향 (1장 p.5)
    '''명칭''': [[후견 편향]] (Hindsight Bias)
    {/def}
    ```
    설명 문장은 슬라이드 정의를 거의 그대로 쓴다(시험이 슬라이드 문장으로 출제될 가능성이 큼). 사례형 설명(bank SA 의 사례 지문 스타일)을 하나 더 붙이면 좋다.

## 5. 정식 문서 키 목록 (링크는 이 키로만)

전체 **229개** = 안내·시험 6 + 장 메인 7 + 사전 216 (서막 26 · 1장 30 · 2장 32 · 3장 32 · 4장 32 · 5장 32 · 6장 32).

## 6. 시뮬레이터 (src/sims/*.js)
심리학 시뮬레이터는 **"한 단계씩 값이 바뀌는 것"만** 만든다(10개). 패널은 코드 대신 **절차·규칙 줄**(`lang:"txt"`)이고, `pc` 는 지금 실행 중인 절차 줄이다. 변수표에는 확률·강도·카운트·판정을 둔다. 슬라이드에 수치가 없는 값(막전위 mV, CR 강도 %, 회상 확률)은 **"표시용 예시값"** 이라고 `desc` 또는 첫 step `note` 에 명시한다.

```js
window.SIMS = window.SIMS || {};
```

엔진 동작 (`SimEngine.mount(containerEl, simName)`):
- 헤더(제목·설명) → 옵션 select 들(바꾸면 build 재실행, step 0) → 컨트롤(⏮ ◀ ▶ ⏭, ▶ 자동재생(속도), 슬라이더, "n / N") → 코드 패널 가로 나열(현재 줄 하이라이트, status 배지) → 변수표(그룹별, 바뀐 값 노란 배경 + 이전값 표시) → 설명 박스 → svg 영역.
- 모바일에서 세로 배치. 키보드 ← → 지원. 각 sim 은 순수 데이터 + build 만 갖는다 (DOM 접근 금지).
- 자동 테스트: `src/test_sims.js` (node) 가 모든 sims 를 로드해 각 옵션 조합으로 build() 를 실행, steps.length>0 이고 pc 가 존재하는 패널 줄 범위 안인지 검사.

## 7. 움직이는 그림 (src/anims/*.js, `[[anim:이름|캡션]]`)

시뮬레이터(§6)가 "값을 한 단계씩 보는 디버거"라면, 움직이는 그림은 '''보고만 있어도 흐름이 들어오는 10초짜리 만화'''다. 심리위키는 시뮬레이터보다 이쪽이 주력이다.
문서에서는 보통 `{def}`/`{analogy}` 다음, `[[sim:]]` 앞에 둔다 — 먼저 그림으로 감을 잡고, 그다음 시뮬레이터로 값을 확인하는 순서.

### 파일 형식 (참조 구현: `src/anims/_reference_ctx_switch.js.txt` — 운체위키 것. 반드시 읽고 `box()`·`txt()`·`show()` 헬퍼와 자막 구조를 본뜰 것)
```js
window.ANIMS = window.ANIMS || {};
ANIMS["pavlov_dog"] = {                 // 이름 == 파일명(pavlov_dog.js). 영문 소문자+밑줄
  title: "파블로프의 개 — 종소리가 침을 부르기까지 12초",
  desc: "한 줄 설명. 인라인 위키 문법([[링크]], '''굵게''') 허용",
  duration: 12,                         // 초. 엔진이 0→duration 을 반복 재생
  build: function () { return '<svg viewBox="0 0 760 330" xmlns="http://www.w3.org/2000/svg">…</svg>'; }
};
```
- `build()` 는 '''순수 문자열'''만 돌려준다. DOM 접근 금지 (`node src/test_anims.js` 가 document 없이 실행한다).
- 시간축은 '''SMIL''' (`<animate>`, `<animateTransform>`, `<animateMotion>`, `<set>`) 로만 만든다. CSS animation·JS 타이머 금지 — 엔진이 `svg.setCurrentTime(t)` 로 시간을 직접 움직이므로 SMIL 만 스크러버/배속/정지에 반응한다.
- 모든 애니메이션 요소는 `begin + dur ≤ duration`. `repeatCount="indefinite"` 를 쓰려면 `dur` 을 반드시 지정. `fill="freeze"` 로 마지막 상태를 유지.
- "t초~t'초에만 보이기"는 `opacity` 를 `values="0;0;1;1;0;0" keyTimes="0;a;a+0.02;b;b+0.02;1" dur="D s"` 로 (참조 구현의 `show()` 헬퍼 참고). keyTimes 는 0 에서 시작해 1 로 끝나고 단조증가.
- `viewBox="0 0 760 H"` (H 는 260~380). `<svg>` 에 고정 `width`/`height` 쓰지 말 것 — CSS 가 100% 폭으로 맞춘다.
- 텍스트 안의 `<`, `>`, `&` 는 `&lt;` `&gt;` `&amp;` 로. (`NS → US` 는 그대로, `CR &lt; UR`, `Hit &amp; FA`)
- `<marker id>` 등 id 는 anim 이름을 접두어로 (`pd_arrow`) — 한 문서에 그림이 여럿 실린다.
- 크기 60KB 이하. 글자 크기 11~15px, 한국어 산문 + 슬라이드 영어 원어 (§4-1 그대로). 사진·실제 인물 얼굴은 그리지 말고 도형·아이콘으로 단순화.
- **색 (심리위키 팔레트)**: 자극/입력(A) `#1d65b3`(연한 `#dbe8f7`), 반응/행동·정답(B) `#2e9e4f`(`#dff3e4`), 학자·강조·주의 대상(C) `#e09a40`(`#fdeec2`), 뇌·신경·내부 과정 `#3b2f4a`(`#efe9f6`), 오류·혐오 자극·함정 `#d6465f`(`#fbe0e5`), 보조 글씨 `#777`. 상태 배지: 강화/증가 `#cdefd2/#1d6b2a`, 중립/대기 `#fdeec2/#8a6000`, 억제/감소 `#dcdcf2/#3c3c88`, 오류/실패 `#ffd9d9/#a52f2f`.
- 구성 규칙: 맨 위 한 줄 '''단계 자막'''(지금 무슨 일이 일어나는지, 시간대별로 바뀜) → 가운데 그림 → 맨 아래 한 줄 '''요점'''. 자막 문장은 문서 본문·슬라이드 정의 표현과 일치시킬 것 (단답형 명칭이 자막에 그대로 등장하도록).
- 시간 설계: 첫 1~2초는 초기 상태를 보여주고, 각 단계 1.5초 내외, 마지막 1.5초는 결과 상태 유지. 8~14초.
- 슬라이드 오류(§4-10)를 그림에 옮기지 말 것 — `split_brain` 은 반드시 좌시야→우반구, 우시야→좌반구.
